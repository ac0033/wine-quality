# 9.1 验收

**结论：执行通过。** 四个候选各评一次，红酒 Ridge、红酒随机森林、白酒随机森林在最终评估集上仍优于基线；白酒 Ridge 的差值区间跨过 0，按 7.1 同一口径记为「验证集上的改善没有在最终评估集上复现」。验收由主 agent（同一执行者）按计划条款自查，证据在文件里可重跑。

## 输入保全与模型不变

`final_evaluation.json` 记录了 11 份输入（两份原始 CSV、划分表、3.1 基线、7.1 比较结果、四个模型文件、两份标准化参数）的字节数与 SHA256，执行前后一致；运行记录的参数里存了四个模型文件哈希的前 12 位。模型用 `joblib.load` 原样加载，没有任何 `fit` 调用。

## 只评一次、只评最终评估行

- notebook 第 3 格从划分表取 `final_evaluation` 行（红酒 318、白酒 994），训练行和验证行只计数、没有进入预测；预测表里每个候选对每条最终评估行恰好一条。
- 复核从原始 CSV 重建特征组合 ID 并核对真值；确认没有训练行或验证行混入；三处故障注入（删一条预测、改一个真值、混入一条验证行）检查器都拒绝。
- 本步之后不再对最终评估集做任何预测；11.1 只登记模型和写交付清单。

## 指标与区间

- 基线只从训练行重算中位数 6.0，MAE / RMSE 与 JSON 一致（1e-10 容差）；四个候选的 MAE、RMSE、差值、按分值行数与误差全部从逐行预测重算一致；各分值行数合计回到 318 / 994。
- 重抽样：有序组合 ID 就是最终评估集特征组合按字典序（红酒 274、白酒 794 个）；2,000 次配对差逐次一致；线性插值区间一致。
- 「仍优于基线」判定按 MAE 低于基线且区间上界小于 0 重算一致；白酒 Ridge 上界 +0.0107，判定为否。

## 验收边界

- 白酒 Ridge 的判定说明的是「这一批最终评估行上看不出稳定改善」，不是「Ridge 对白酒没用」；它的 MAE 仍低于基线 0.0275。
- 红酒最终评估 MAE 比验证集略低，主要因为这批行 quality=6 的占比低，基线更差；不能解读为模型变好了。
- 最终评估行在 2.1 被全量探索看过；本步的数字不能当作对未来样本的保证。
