# 2.1 第二步报告：红酒与白酒的探索分析

**本步已完成，并通过主 agent 验收。** 在红酒 1,599 行、白酒 4,898 行原始记录中，`alcohol` 与 `quality` 均呈正向观察关系；其他指标的关系在红酒和白酒之间有差异。结果可用于确定后续要验证的问题，尚不能说明评分原因或预测效果。本步保留全部原始行，原始数据变化为 **0 行、0 列、0 个值**。

## 哪些指标与 `quality` 的关系值得继续核对？

分别读取 [红酒原始 CSV](../../../data/winequality-red.csv) 和 [白酒原始 CSV](../../../data/winequality-white.csv)，按第一步的 [数据概况](../../01_数据预处理/1.1_原始数据理解与质量核验/outputs/data_profile.json)核对表头、行数和 `quality` 频数，再计算各自 11 个理化指标与 `quality` 的 Pearson、Spearman 系数，以及各 `quality` 分组的指标中位数。下表选出能说明共同点和差异的四个指标；**全部 11 个指标**及两种系数、分组结果均保存在 [完整统计](outputs/eda.json)，由 [分析代码](src/analyze.py)复现。

| 指标 | 红酒与 `quality` 的 Spearman | 白酒与 `quality` 的 Spearman | 观察到的问题 |
|---|---:|---:|---|
| `alcohol` | +0.4785 | +0.4404 | 两类酒中方向一致，值得进一步检查其独立信息 |
| `volatile acidity` | -0.3806 | -0.1966 | 两类酒都为负，强度不同 |
| `density` | -0.1771 | -0.3484 | 白酒中的负向关系更明显 |
| `sulphates` | +0.3771 | +0.0333 | 红酒为正，白酒接近零 |

这些系数以各自文件的**全部原始行**计算，没有把红酒和白酒合并。Pearson 描述线性关系，Spearman 按并列值的平均秩描述单调关系；两者都没有控制其他指标。[关系图](figures/spearman_quality.svg)显示全部 11 个 Spearman 系数，[`quality` 分布图](figures/quality_distribution.svg)给出每类酒的分值行数和比例。两类酒的 `quality=5–6` 分别为红酒 **1,319/1,599 行（82.5%）**、白酒 **3,655/4,898 行（74.6%）**；较少见的分值不能凭整体关系推断其表现。

一个可追溯的例子是红酒 CSV 第一条记录：`7.4;0.7;0;1.9;0.076;11;34;0.9978;3.51;0.56;9.4;5`。按分号读入后，最后两列为 `alcohol=9.4`、`quality=5`；这行计入红酒 5 分的 **681 行**，该组 `alcohol` 中位数为 **9.7**。红酒 7 分的 **199 行**中位数为 **11.5**。这些分组结果在 [完整统计](outputs/eda.json) 的 `by_quality` 中；它们说明观察到的差异，不能说明改变某一份酒的 `alcohol` 会改变评分。

## 分布和完全相同的整行会怎样影响解读？

按全部原始行计算的分位数显示，白酒 `residual sugar` 中位数为 **5.2**，四分位数为 **1.7、9.9**，最大值为 **65.8**；红酒对应为 **2.2**、**1.9、2.6**、**15.5**。这些范围保存在 [完整统计](outputs/eda.json) 的 `distribution` 中。最大值远离中间一半记录的范围，提示看单一均值或相关系数时还要注意分布形状；它本身不能证明录入错误，所以没有据此删行。

第一步发现红酒有 **240 行**、白酒有 **937 行**与本文件此前某行的 12 个原始字段值完全相同。本步仍以全部 **1,599 / 4,898 行**为主口径，只另外计算“每组同值行保留首次出现的行”的敏感性结果：红酒 **1,359 行**、白酒 **3,961 行**。两种口径下，11 个指标与 `quality` 的 Spearman 均未变号，也没有绝对差达到计划设定的 **0.10**；最大绝对差分别为红酒 `chlorides` **0.0144**、白酒 `alcohol` **0.0353**。对照结果在 [完整统计](outputs/eda.json) 的 `sensitivity` 中，**没有生成清洗后的数据集**。由于没有样本 ID，不能判断同值行是否为重复采集，也不能把敏感性口径替代主分析。

## 这些结果能支持下一步做什么？

[完整统计](outputs/eda.json)还保存每类酒 11 个理化指标两两之间的 Spearman 系数：红酒 `free sulfur dioxide` 与 `total sulfur dioxide` 为 **+0.7897**，白酒 `density` 与 `alcohol` 为 **-0.8219**。这提示若以后要预测 `quality`，需检验指标是否提供彼此独立的信息；本步没有据此选择特征。当前数据也没有样本 ID 或采集时间，无法确认同值行身份、控制所有可能的共同影响，或判断结果能否推广到其他葡萄酒。11 个指标的相关系数只是探索结果，未作显著性检验、因果识别或模型评估。

[独立复核结果](checks/verification.json)为 **980/980 项通过**：从原始 CSV 另算行数、`quality` 频数、各指标分布、选定指标的分组中位数与相关系数、全部指标的同值行敏感性结果，并检查两张图与 JSON 的数字。主 agent 又从原始 CSV 复算关键关系和分位数，记录在 [验收结论](acceptance.md)。三份原始文件及第一步两份输入产物的字节数和 SHA256 前后一致；运行与失败尝试保存在 [执行日志](execution.jsonl)。这些检查支持**本数据集内的描述正确性**，尚不能替代下一步对预测用途、预测时点、数据切分、基线和评价指标的定义。
