# 第四步计划检查：方向可保留，执行前需补齐验收口径

**结论：研究方向合理；原计划需要补充后再交用户评估，第四步未执行。** [现有计划](plan.md)承接第三步固定划分，分别比较红酒、白酒的 Ridge 与随机森林，并以训练中位数为基线。这能回答“这两种预定候选在当前验证集上是否改善评分估计”，不能回答所有模型是否有效，或是否已经适合生产使用。

本次没有修改原计划的候选范围、参数、数据划分或通过门槛。以下是需要并入计划的具体条款；它们是待评估的计划补充，不是已执行结果。

## 已核对的依赖与可保留部分

从两份原始 CSV 和第三步逐行划分表重新核对：红酒训练 **950 行**、验证 **331 行 / 274 个特征组合**；白酒训练 **2,921 行**、验证 **983 行 / 794 个特征组合**。训练中位数均为 **6.0**，验证 MAE 为 **0.6435045317 / 0.6368260427**，RMSE 为 **0.8777201999 / 0.9032551059**（红酒 / 白酒，单位为评分分数）。与原计划及[第三步基线](../../03_数据划分/3.1_预测任务定义_固定划分与验证基线/outputs/baseline_validation.json)一致，独立复核见[本轮验收](../../../reviews/report_review/acceptance.md)。

可以保留：使用全部 11 个指标；红白酒分别训练；Ridge 标准化只拟合训练行；随机森林采用预定参数；不反复用验证集调参；最终评估行不输出预测或误差。两类模型覆盖线性与非线性候选假设，但同时改变了模型结构、拟合方式等因素，不能把两者成绩差全归因于“非线性”。

## 1. 准确交代最终评估数据已经参与过探索

**问题与影响：** 第二步在全部 6,497 行上计算了指标与评分的关系，之后第三步才划分数据。因此“最终评估集继续封存”容易被理解为从未查看过这些记录，与实际项目顺序不符。

**补充条款：** 最终评估集尚未用于模型预测、误差计算或候选调参；其记录此前已参与全量探索。第四步保持固定划分，不再用最终评估行作方向决策，模型训练与预测接口只接收训练、验证部分。读取全量数据进行输入指纹及划分完整性检查，与使用最终评估数据作模型评价，应在代码中区分。后续最终评估须披露已有探索接触，不能称为完全未接触的外部验证；若要验证未来场景，需要另立计划获得新数据。

**验收：** 代码审查检查拟合和预测实际接收的行号与字段，逐行预测文件只含验证行；报告保留上述边界。日志自述“未使用”不能单独证明隔离。

## 2. 把重抽样区间写到可以独立重做

**问题与影响：** 原计划给出 2,000 次、种子和分位点，却没有明确抽样组合数、组合顺序、随机数实现、重复抽中时的权重与分位数算法；验收条款也未要求独立重算区间。区间上界决定候选是否被登记，因此必须成为验收对象。

**建议补充的固定规则：** 每类酒的验证特征组合 ID 按字典序排列。分别初始化 `numpy.random.Generator(numpy.random.PCG64(20260914))`，每次从 G 个组合中等概率、有放回抽取 G 个索引；红酒 G=274，白酒 G=794，重复 2,000 次。同类酒的两个候选与基线使用完全相同的抽样索引。同一组合抽中几次，就将其全部验证行计入几次；每次按抽中后的原始行数求平均，不先求组合均值再给每个组合相同权重。固定模型预测，不在重抽样中重新训练。对 2,000 个“候选 MAE − 基线 MAE”排序，以线性插值计算 2.5% 和 97.5% 分位数。

**真实结构例子：** 红酒第 1、5 行属于同一验证特征组合，基线对两行的绝对误差各为 1。若一次重抽样把这个组合抽中两次，这两条原始行各计两次，基线绝对误差和增加 4，分母增加 4；候选使用相同四次计入。候选预测尚未产生，此处不填写候选误差。该规则使区间与原计划按原始行计算 MAE 的口径衔接。

**产物与验收：** 建议新增 `outputs/bootstrap_draws.json` 保存各酒类有序组合 ID、抽样索引、算法和种子，`outputs/bootstrap_mae_differences.csv` 保存每次每候选配对差。两份文件尚未生成。独立复核代码从原始真值、逐行预测和抽样索引重算全部 2,000 次差值与区间，并检查索引来自正确验证组合、每次恰好抽 G 次。误差指标和区间采用 `1e-10` 绝对容差。原始行级预测文件须包含 `wine`、`source_row`、`feature_group_id`、候选名称、真值、原始连续预测、基线预测及双方误差，支持复核。上述文件均写入第四步目录。

该区间只描述固定预测在当前验证组合重抽样下的波动，不包括重新训练、重选划分、多个候选选择或未知样本依赖带来的全部不确定性。未进行多重比较校正，不将上界小于 0 表述为多候选选择后得到的严格显著性保证。

## 3. 固定预测口径，并区分研究筛选与实际收益

**问题与影响：** 连续预测若事后取整或截断，MAE 与 RMSE 会改变；原计划没有写明。另一个问题是，区间上界小于 0 并未规定改善多少才有实际使用价值。

**补充条款：** 两类候选均用原始连续输出评分，不取整、不截断到 0–10。固定训练行顺序为原始行号升序、字段顺序为第三步 11 个指标顺序；训练前记录实际库版本和全部有效参数，标准化参数另存第四步产物。原计划的 MAE、区间上界与 RMSE 门槛仅用于登记进一步验证的候选，不代表生产收益门槛。当前没有实际成本或最低有用改善幅度的业务依据，本步不编造此门槛。

若两个候选都满足原门槛，完整登记两者，不因本步报告只能展示一个而事后引入未规定的决胜规则。若均不满足，只能说本次两种固定配置未获得足够支持，不能推断全部 11 个指标没有预测信息。按 `quality` 报告误差时附行数及组合数；白酒 9 分验证仅 1 行、红酒 3 分仅 2 行，仅描述这些记录的结果。

**验收：** 独立重算使用未经取整、截断的预测；逐分值行数合计回到 331 / 983。所有候选均在完整结果中出现，包括无提升结果。无需扩大本步为调参或特征选择。

## 4. “本步执行通过”与“候选满足门槛”分别判定

**问题与影响：** 模型没有优于基线也可能是正确完成的实验；数据覆盖、指标或隔离错误才是执行验收失败。原计划产物还缺少明确独立文件 `acceptance.md`，区间与拟合边界的验证也不完整。

**补充条款：** 第四步必须交付 `report.md` 与 `acceptance.md` 两份独立报告。用户报告说明比较结论和使用意义；主 agent 验收报告说明输入保全、拟合范围、预测覆盖、逐行真值、全部指标及重抽样区间的核对方法和判定。没有提升时，执行仍可通过，但候选登记结论为“不满足门槛”。出现输入指纹变化、覆盖不全、非有限预测、指标不符或最终评估参与拟合/预测时，执行不通过，在本步查因修正。

独立复核需校验预测表真值与原始 CSV 一致，不能仅信任表内真值；检查组合 ID 与第三步对应。使用内存副本故意删除一条验证预测、改变一个真值、加入最终评估行，确认检查器分别拒绝；故障注入不得写回权威产物。拟合边界采用代码与实际训练行清单审查，不把指标重算通过当成无泄漏的证据。

## 停点

以上补充并入计划、经用户评估且执行 agent 已安排后，才启动第四步。当前仅完成计划检查，没有候选模型、预测文件、重抽样结果或模型胜出结论。原计划及原有第三步划分和基线均保留。
